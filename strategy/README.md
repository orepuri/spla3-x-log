# Splatoon 3 Strategy Memo Sample

This package contains sample strategy data for:

- ガチアサリ / ナメロウ金属 / スプラシューター
- ガチアサリ / リュウグウターミナル / スプラシューター

Files:

- `strategy_memos.yaml`: app data sample
- `assets/strategy-maps/*.svg`: original schematic map images

The SVG maps are original simplified diagrams. They are not official Nintendo maps.
